    Cara Kerja

    Bagaimana Model Menemukan Garis Terbaik?

    Coba geser sendiri garisnya dan lihat error-nya berubah.

    y = β0 + β1x + ε
    • y = tip (variabel dependen)
    • x = total_bill (variabel independen)
    • β0 = intersep, tip prediksi saat tagihan 0
    • β1 = koefisien (slope), kenaikan tip per kenaikan $1 tagihan
    • ε = error, selisih tip aktual dan tip prediksi
    1. Tarik sebuah garis lurus melalui sebaran data.
    2. Ukur seberapa jauh garis dari titik-titik data memakai cost function (MSE).
    3. Ubah β0 dan β1 sedikit demi sedikit ke arah yang menurunkan error (gradient descent), seperti turun ke lembah, sampai error paling kecil.

    Catatan dan Keterbatasan

    • R² sekitar {{ '%.2f'|format(metrics.r2) }} berarti sisa variasi tip dipengaruhi faktor lain yang tidak dipakai (misalnya jumlah orang dan kebiasaan pelanggan).
    • Model ini regresi linear sederhana: hanya satu variabel input (total_bill).
    • Prediksi di luar rentang ${{ '%.2f'|format(metrics.x_min) }} - ${{ '%.2f'|format(metrics.x_max) }} kurang andal karena di luar data latih.
    • Datanya sampel terbatas ({{ metrics.n_total }} transaksi) dalam dolar AS, sehingga belum tentu mewakili restoran lain.
    • Hubungan tagihan dan tip adalah hubungan statistik, bukan jaminan bahwa tip selalu sebesar hasil prediksi.

    FAQ

    Pertanyaan Umum

    Metode untuk memodelkan hubungan garis lurus antara satu variabel input (X) dan satu variabel output (y). Di sini X adalah total tagihan dan y adalah besar tip.

    R² menunjukkan berapa persen variasi tip yang dapat dijelaskan oleh total tagihan. Nilainya {{ '%.2f'|format(metrics.r2) }}, artinya sekitar {{ (metrics.r2 * 100)|round(1) }}%.

    Model hanya memakai total tagihan. Faktor lain seperti pelayanan dan kebiasaan pelanggan tidak ikut dihitung, sehingga prediksi rata-rata meleset sekitar ${{ '%.2f'|format(metrics.rmse) }} (RMSE).

    Boleh, tetapi hasilnya kurang andal. Model dilatih pada tagihan ${{ '%.2f'|format(metrics.x_min) }} sampai ${{ '%.2f'|format(metrics.x_max) }}, dan aplikasi akan menampilkan peringatan di luar rentang itu.
